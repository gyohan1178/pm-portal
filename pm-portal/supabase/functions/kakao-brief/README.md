## ① 카카오 디벨로퍼스 (developers.kakao.com) — 카카오 계정으로 로그인
1. 내 애플리케이션 → **애플리케이션 추가** (앱 이름 예: `JS 포털 알림`, 회사명 `진선테크`)

3. 플랫폼 → **Web** 등록 → 사이트 도메인 `https://pm-portal-29q.pages.dev`

6. (선택) 보안 → Client Secret 코드 생성 · 활성화 → 켰다면 그 값도 ②에 넣는다

   - 팀원도 쓰려면: 앱 → 팀 관리에 팀원 카카오 계정을 추가해 두면 막힘이 적다
